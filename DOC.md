# DOC

### Introducción

- Este es un modelo de proyecto tipo portfolio para profesores y académicos.
- Deben primar los estilos simples y legibles y pocos efectos visuales -hovers, transitions, etc.-
- Todo Debe ser fácil de entender y usar.
- El proyecto usa Keystatic para administrar los contenidos y Cloudflare para publicar el sitio online.

### Estructura

- Home: Muestra el header, la información básica de la persona -sin foto- y luego una muestra de los elementos de cada sección, con cards.
- Publicaciones: Cards de publicaciones, extendidas de ancho.
- Proyectos: Cards de publicaciones.
- Videos: Cards de videos, con previews de youtube.
- Blog: Cards de entradas.
